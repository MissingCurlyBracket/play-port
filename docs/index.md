## Project Overview

play-port is a streaming-service locator for movies and TV shows. A user searches
a title and play-port shows where it can be streamed in their region, on their
preferred providers, using data proxied from [TMDB](https://www.themoviedb.org/)
and enriched with IMDb metadata from [OMDb](https://www.omdbapi.com/).

The repository holds one npm package that builds two independently deployed
artifacts: a React single-page app (GitHub Pages) and a set of AWS Lambda
functions (Serverless Framework).

## Project Structure

This project consists of 2 parts:

### Frontend SPA (web)

- **Type:** web (React SPA)
- **Location:** `src/`
- **Tech Stack:** React 19, TypeScript, Vite 7, TanStack Router + Query, MUI 7, Tailwind CSS 4
- **Entry Point:** `src/main.tsx`

### Serverless API (backend)

- **Type:** backend (serverless functions)
- **Location:** `functions/`
- **Tech Stack:** AWS Lambda (Node.js 24), Serverless Framework 4, esbuild, TypeScript
- **Entry Point:** `functions/handler.ts`

## Cross-Part Integration

The SPA never calls TMDB/OMDb directly. Class-based API clients in `src/api/`
issue HTTP `GET` requests to the Lambda API (base URL from `VITE_API_BASE_URL`),
and each Lambda handler proxies the upstream provider server-side so API tokens
never reach the browser. In dev, MSW (`src/mocks/`) intercepts these calls and
serves fixtures instead of hitting the backend. See
[integration-architecture.md](./integration-architecture.md).

## Quick Reference

### Frontend SPA Quick Ref

- **Stack:** React 19 + Vite + TanStack Router (hash history) + TanStack Query + MUI + Tailwind
- **Entry:** `src/main.tsx` → `RouterProvider` with injected API clients in router context
- **Pattern:** Atomic-design components; container routes prefetch via Query; presentational pages

### Serverless API Quick Ref

- **Stack:** AWS Lambda (Node.js 24), HTTP API events, esbuild bundling
- **Entry:** `functions/handler.ts` (one exported handler per endpoint)
- **Pattern:** Stateless proxy — fetch upstream, reshape to a lean DTO, return JSON with CORS headers

## Getting Started

### Frontend SPA Setup

**Prerequisites:** Node.js 24, npm

**Install & Run:**

```bash
npm install
npm run dev        # Vite dev server; MSW mocks the backend automatically
```

### Serverless API Setup

**Prerequisites:** Node.js 24, npm, a TMDB v3 read access token (and optional OMDb key)

**Install & Run:**

```bash
npm install
npx serverless offline   # runs the Lambda handlers locally
```
